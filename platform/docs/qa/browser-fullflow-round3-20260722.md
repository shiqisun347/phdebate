## ISSUE-001：手机端“比赛操作”面板存在无文字的空白按钮

| 字段 | 内容 |
|---|---|
| 严重度 | P2 / Medium |
| 分类 | 移动端 UI、可发现性 |
| 房间 | `358554` |
| 页面 | `/rooms/358554/debate` |
| 证据 | [房主继续比赛后的手机端控制面板](browser-fullflow-round3-20260722/screenshots/resumed-mobile.png) |

**现象**

在 390×844 手机视口打开“比赛操作”后，面板中“暂停比赛”和“仅退出比赛页面”对应的按钮只显示白色矩形边框，肉眼看不到按钮文字；“提前结束比赛”的红色按钮文字正常。无障碍树仍能识别这些按钮，因此功能本身存在，但普通用户无法知道两个空白区域能做什么。

**复现步骤**

1. 在手机视口进入一场进行中的比赛。
2. 点击底部齿轮“比赛操作”。
3. 观察控制面板中的三个操作按钮。
4. “提前结束比赛”可见，另两个按钮显示为空白白色块。

**建议**

- 检查浅色主题下次要按钮的文字颜色是否继承成白色或透明。
- 给三个操作按钮统一设置显式的前景色、禁用色和焦点色。
- 增加 390×844 的视觉快照测试，断言按钮可见文本与对比度。

**修复回执**

- 已为浅色比赛操作面板的次要按钮设置显式文字色、边框色、背景色、悬停色和禁用色，不再继承旧深色主题的白色文字。
- 新增 CSS 合约测试，固定正常态与禁用态的前景/背景颜色。
- `free-turn-queue-layout` 与 `DebateStage` 定向回归：`73 passed`、`21 skipped`；Next.js 生产构建通过。
- 已发布 `round53-realtime-mobile-controls-20260722`。生产 390×844 舞台计算样式复测：文字 `rgb(53, 87, 125)`、背景 `rgb(247, 249, 252)`、边框 `rgb(213, 224, 236)`，不再是白底白字。
- 状态：已修复并完成生产 CSS 复测。

## 核心回归一：终止时存在未提交文字发言

### 测试步骤

1. 房主和真人参赛者创建并开始 1v1 房间 `232594`。
2. 正方立论开始后，房主进入“麦克风不可用？改用文字发言”。
3. 输入一段文字，但不点击“提交本轮发言”。
4. 返回语音发言界面，页面正确显示“文字内容仍在本页 / 继续文字发言”。
5. 房主打开“比赛操作”，确认提前结束比赛。
6. 系统打开专用终态面板，而不是丢弃草稿或继续显示可发言状态。
7. 面板恢复完整草稿，并明确提示“比赛已结束，本轮文字尚未提交”。
8. 用户点击“放弃未提交内容并查看结果”。
9. 浏览器自动进入 `/rooms/232594/result`，结果页显示“比赛已终止”。

### 结果

通过。

- 草稿在终止瞬间没有静默丢失。
- 草稿没有被错误写入正式发言记录。
- 用户必须明确确认放弃未提交内容。
- 确认后能自动跳转结果页。
- Round 2 中“终止后停在辩论页并显示比赛尚未开始”的问题未复现。

## 核心回归二：真人断线 60 秒自动暂停且不允许 AI 接管

### 测试步骤

1. 房主和真人参赛者创建并开始 1v1 房间 `358554`。
2. 比赛进入正方立论，正方房主拥有当前发言权。
3. 完全关闭反方真人的浏览器会话，模拟设备离线。
4. 在 60 秒宽限期内观察房主和匿名观众页面。
5. 超过 60 秒后观察状态、计时器、席位和操作按钮。
6. 重新启动反方浏览器、登录并返回比赛页。
7. 反方确认接管自己的原席位。
8. 确认比赛仍保持暂停，没有自动恢复。
9. 房主在“比赛操作”中显式点击“继续比赛”。
10. 确认比赛从原正方立论进度恢复，原真人席位仍属于原用户。

### 结果

通过。

- 宽限期内显示“席位保留 60 秒，超时自动暂停，不会由 AI 接替”。
- 断线超过 60 秒后，页面自动进入“等待真人辩手重新连接”。
- 倒计时停留在 `00:56`，比赛进度被保存。
- 房主页明确显示“系统不会安排 AI 接管”。
- 反方席位始终保持真人身份和原用户名，没有出现 AI 或 `AI 接替` 标识。
- 匿名观众页同步显示暂停，不泄露控制能力。
- 真人重连后，双方页面显示“全部真人已重新连接”，但比赛仍保持暂停。
- 房主必须显式点击“继续比赛”；点击后恢复到原正方立论和原剩余时间。

## 产品与状态一致性结论

- 终止、草稿恢复和结果导航已经形成闭环，不会再让用户停留在失效的辩论状态。
- 60 秒断线策略在房主、参赛者和观众三个投影上保持一致。
- “真人断线暂停”与普通服务异常暂停的核心操作路径一致，但提示更明确，用户知道必须等待真人返回。
- 重连只恢复连接和席位控制，不会偷偷推进计时或自动继续比赛，符合房主显式确认的安全原则。
- 桌面端和手机端都能完成核心恢复操作；手机端仅存在上述控制面板文字不可见问题。
