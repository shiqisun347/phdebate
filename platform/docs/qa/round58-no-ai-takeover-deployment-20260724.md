# Round 58 真人断线与禁止 AI 接管发布记录

日期：2026-07-24  
生产环境：`https://117.50.192.216`  
发布版本：`round58-no-ai-takeover-20260724`

## 已生效规则

- 已开赛的真人席位不会被转换为 AI，用户 ID、姓名和席位保持不变。
- 开赛时从未被真人认领的空席仍可按赛事规则补为永久 AI；这不是对真人席位的接管。
- 真人连续离线满 60 秒后，整场比赛自动暂停。
- 断线到期会中断当前 Speech、Agent、TTS 和 LiveKit generation，并通知浏览器清空未播放音频。
- 真人重连不会自动恢复比赛；所有真人恢复在线后，仍须由房主或系统管理员明确继续。

## 本轮关键修复

旧调度器在房间任务阻塞于 Agent 或 MOSS 调用时会跳过该房间，导致 60 秒暂停可能被外部调用延后。本轮新增独立的断线安全扫描，并在 TTS 取消谓词中直接检查超时真人，使暂停边界不再依赖房间任务返回。

前端同时增加服务端权威断线倒计时、`真人 · 在线/已断线` 席位标识，以及到期后的“正在自动暂停”状态；到期时禁用会与自动暂停竞态的暂停和跳过操作。
