# Round61 `image.png` 比赛现场视觉验收

日期：2026-07-24

状态：本地实现并通过测试，尚未部署。生产环境房间 `117519` 仍在比赛中，避免热更新影响现场。

## 设计映射

参考图被拆分为四个稳定区域，而不是作为一张背景图复刻：

1. 顶部赛事栏：品牌、赛事/房间、辩题、实时连接状态。
2. 比赛舞台：左右队伍、当前阶段、当前发言人、波形和权威计时。
3. 底部操作区：本人席位、发言主按钮、文字记录、暂停/继续、声音、全屏和更多控制。
4. 右侧工作区：参赛者可打开文字记录；匿名观众无入口且后端投影不返回文字稿。

参考图中的人物插画属于独立资产层。当前项目没有经过授权、风格统一的头像素材，因此使用稳定的姓名首字头像，没有用 CSS 伪造人物插画。

## 本轮实现

- 桌面比赛页改为高密度三栏“比赛驾驶舱”，完整展示 4v4 席位。
- 正反双方分别使用红、蓝辨识轴；真人和 AI 显示明确身份标签。
- 中央增加当前发言人焦点、连续波形、数字计时和实时字幕区。
- 房主的暂停/继续移动到底部快捷控制区，设置弹窗不再重复同一操作。
- 文字记录通过 Portal 渲染到页面根节点，修复其被底栏 `backdrop-filter` 限制、只能显示 36px 高度的问题。
- 手机端改为内容驱动的两段舞台，完整显示 8 个席位；底部保持举手队列和固定控制区。
- 手机底栏去掉被截断的重复姓名文字，仅保留本人头像；席位身份仍在舞台中完整可见。
- 观战页复用同一舞台，但不显示文字记录、发言和比赛控制。
