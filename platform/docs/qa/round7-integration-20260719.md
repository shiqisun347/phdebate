# Round 7 整合验收

日期：2026-07-19

## 本轮结果

Round 7 在不修改可靠实时语音与浏览器播放基线的前提下，完成四类改进：

1. 赛果发言使用签名 keyset 游标分页，结果页支持加载更早发言、稳定去重和刷新保留。
2. 结果时间线取消不可发现的嵌套滚动，归档事件进入正常文档流。
3. 管理后台从单个 2404 行页面拆成按需加载模块，主页面降至 1172 行。
4. 公开大厅修复赛事统计 N+1、私密房间误计数、假空状态、状态自动同步和长期暂停房间占位。

## 生产浏览器发现与处理

| 问题 | 处理 |
| --- | --- |
| 48 条结果事件只能通过页面滚动看到前 10 条 | 结果时间线取消 `max-height` 与嵌套滚动；控制台时间线保持受控滚动。 |
| 当前反方席位高亮时显示上一段正方发言，语义不清 | 房间投影把非活动字幕标记为“上一段发言 · 席位”。未修改 DebateStage。 |
| 匿名结果暴露上线、离线、设备控制和音频诊断事件 | 公开赛果采用比赛叙事事件白名单；参赛者/管理员继续保留完整审计记录。 |
| 暂停约 5 小时的房间仍占据公开大厅 | 最近暂停显示暂停时间和恢复状态；超过默认 1 小时后从大厅及可观战计数下架。 |

匿名实时观战仍保留阶段、字幕及连续播放所需的最小音频事件；隐私修复没有删除实时播放器
依赖的 generation、speech ID 或中断信号。

## 部署后复验要求

- 匿名打开长结果页，全部已加载事件应随正常页面滚动可达。
- 匿名结果不得出现 presence、设备控制、Provider 或音频内部事件。
- 暂停房间应显示暂停时间；超过阈值的暂停房间不再出现在公开大厅。
- 观战中央显示历史内容时，发言人标签必须包含“上一段发言”。
- 首页桌面和手机 Web Vitals 不应明显劣于本轮修改前基线。
