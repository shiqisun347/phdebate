# Round 62：完整比赛稳定性与多人实测

## 结论

本轮代码已完成完整 4v4 状态机、双浏览器多人大厅、断线限制、房主控制入口、匿名观战脱敏、实时语音文本分块和移动端参赛入口的联合修复与回归。生产服务器仍有房间 `#117519` 正在比赛，因此本轮改动仅保留在本地，未热更新生产环境。

## 主要修复

- 正式环境开赛前必须保证所有已认领真人席位在线且准备完成。
- 真人断线不再由 AI 接管；比赛中断线超时进入安全暂停，恢复由房主明确执行。
- 预设主持提示音在开赛前一次性校验，缺失、损坏、空 WAV 或文本不一致都会阻止开赛。
- 房主辩手页增加“进入完整比赛控制台”，异常时可主动检查、重试、跳过或终止。
- 控制台明确显示自动流程当前步骤；服务异常与真人断线同时发生时，不再错误开放恢复操作。
- 已在未结束比赛参赛的用户，参赛弹窗直接提供返回入口并禁用新建房间流程。
- 普通辩手准备后显示“取消准备”，不暴露房主操作。
- Agent 增量文本保留英文词间空格，避免 TTS 将英文单词黏连朗读。
- 生产配置继续强制单一实时语音链路、禁止完整 WAV 播放回退、禁止保存比赛音频。
- 参赛选择卡片改为图标与两行文字的稳定栅格布局，移动端不再出现标题与说明黏连。
