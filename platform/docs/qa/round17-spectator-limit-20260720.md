# Round 17：单房间最多 20 人观战

日期：2026-07-20

## 产品规则

- 每个房间同时最多允许 20 个观战 WebSocket。
- 匿名观众和未占席位、无控制权限的登录用户计入上限。
- 辩手、房主和系统管理员不占观战名额，断线恢复和比赛控制不受观众满员影响。
- 第 21 位观众由服务端以 WebSocket 关闭码 `4429` 拒绝，网页显示“本场观战人数已达 20 人，请稍后重试”。
- 观众正常退出、异常断网或 API 进程退出后，名额通过显式释放或 60 秒 Redis 租约到期自动回收。

## 实现

- Redis 有序集合和 Lua 脚本原子完成清理过期租约、计数和占位，两个 API Worker 共享同一个房间上限。
- 生产环境 Redis 不可用时对新增观众失败关闭，避免多个 Worker 各自放行 20 人；辩手和控制者仍可连接。
- 浏览器心跳与房间事件都会续租。登录用户在观战、认领席位和获得控制权之间切换时，会动态释放或申请观战名额。
- 生产验收工具改为验证 20 人成功、第 21 人返回 `4429`、已有连接释放后替补观众成功进入。
- 通用观战压测工具按房间数校验容量，最多按每房 20 人分配，不再把单房 500 人作为正确产品行为。
