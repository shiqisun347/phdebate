# Round 63：旧产品表面清理

日期：2026-07-24  
范围：唯一 `platform` 版本；未部署；未修改比赛推进、断线暂停或计时状态机。

## 结论

- 当前页面和公开接口继续以“赛事、房间、辩手、观战、系统播报”为唯一产品语义。
- 管理员初始化变量已从 `V2_ADMIN_*` 改为 `ADMIN_*`；MOSS Supervisor 根目录变量已改为 `PHDEBATE_ROOT`。
- 浏览器与 API 不再读取 `jixia_v2_*` Cookie；旧 Cookie 不会建立登录身份。
- 真人发言录音上传路由已从 FastAPI/OpenAPI 删除。保留同名 Python 兼容函数，仅用于让历史内部导入安全失败：固定返回 410，不读取请求体、不创建目录、不写文件。
- 比赛页面移除了“无需主持人”的否定式旧角色文案，改为正向说明“系统按预设流程完成播报与赛程推进”。
- 官方 README 明确比赛只保存文字记录，不再展示并行录音上传验收入口。

## 关键边界

- 管理员预先制作、所有比赛复用的系统提示音仍由 `/media/_cues/*` 提供。这不是比赛发言录音归档。
- 数据库中的历史 `audio_url` 字段和旧迁移记录没有在本轮破坏性删除；它们只承担历史数据兼容，不构成新的上传入口。
- 本轮没有改动 `/ws/rooms/:code` 房间事件、ASR、LiveKit 发布、阶段推进或断线 60 秒暂停逻辑。
