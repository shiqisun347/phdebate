## 问题

### ISSUE-001 · P1 · 匿名访客可读取暂停比赛的完整逐字稿和原始录音入口

**影响**

公开观战是合理功能，但原始音频、完整逐字稿和真人身份属于更高敏感度的数据。六位数字房间号空间较小，且房间号本来就用于分享；当前行为会使未结束比赛的学生发言数据在没有登录、没有参赛关系、没有显式发布动作的情况下可访问。

**复现**

1. 退出登录，进入 `https://117.50.192.216/rooms/551958/result`。
2. 页面无需认证即可加载。
3. 页面显示真人姓名、完整发言文本、录音时长和浏览器音频播放控件。
4. 比赛此时仍为“比赛已暂停”，不是已发布终局结果。

**证据**

- `/tmp/round12-browser/screenshots/paused-room-anonymous-result.png`
- `/tmp/round12-browser/screenshots/anonymous-paused-result-390.png`

**建议**

1. 将“观战投影”和“研究数据/完整结果”拆成独立权限模型。
2. `running`、`paused`、`review_required` 状态下，匿名 `/result` 应跳回 `/watch`，或只显示与观战页等价的脱敏投影。
3. 完整逐字稿、音频资产和个人评分仅向参赛者、房主、管理员开放。
4. 若赛事确实需要公开赛后记录，应增加赛事级 `result_visibility` 和单场“发布结果”状态；默认不公开原始音频。
5. 音频 URL 必须在服务端鉴权，不能只靠前端隐藏播放器。
6. 增加测试：匿名、普通非参赛用户、参赛者、房主、管理员 × lobby/running/paused/completed/review_required。

### ISSUE-002 · P2 · 暂停比赛被表达为“裁判评议中、等待管理员复核”

**影响**

页面顶部正确显示“比赛已暂停”，但同页裁判卡片写着“裁判评议中”和“结果等待管理员复核后发布”。实际上比赛只完成了 2 次发言，尚未进入裁判阶段。学生会误以为比赛已经结束且卡在人工审核，房主也难以判断应恢复比赛还是联系管理员。

**复现**

1. 打开 `/rooms/551958/result`。
2. 观察页面顶部“比赛已暂停”。
3. 向下观察裁判卡片，显示“裁判评议中”和“结果等待管理员复核后发布”。

**证据**

- `/tmp/round12-browser/screenshots/paused-room-anonymous-result.png`
- `/tmp/round12-browser/screenshots/anonymous-paused-result-390.png`

**建议**

- 非终局状态不要渲染裁判状态卡；改成“比赛尚未结束，恢复后继续生成赛果”。
- 仅 `judging` 显示“裁判评议中”，仅 `review_required` 显示“等待管理员复核”。
- 在暂停状态优先给有权限用户展示“返回控制台/恢复比赛”，观众只显示“返回比赛现场”。

### ISSUE-003 · P2 · 少量时间线事件时容器产生巨大空白

**影响**

桌面和手机结果页的“比赛时间线”在仅有少量事件时仍占据接近一整屏的固定高度。390 px 手机页面出现约千像素空白，显著增加滚动成本，也使页面看起来像数据加载失败或渲染中断。

**复现**

1. 打开 `/rooms/551958/result`。
2. 滚动到“比赛时间线”。
3. 12 个事件只使用容器上部，余下区域为空；手机端更明显。

**证据**

- `/tmp/round12-browser/screenshots/paused-room-anonymous-result.png`
- `/tmp/round12-browser/screenshots/anonymous-paused-result-390.png`

**建议**

- 去除以视口为基准的 `min-height`；让容器按事件内容自然增长。
- 大量事件时使用分页/折叠或“加载更多”，不要用固定大容器预留空间。
- 添加 0、1、8、50 条事件的 390/768/1440 视觉回归测试。

## 产品与可用性观察

- 三种尺寸的大厅视觉层级清楚，主操作突出，移动端没有把赛事卡片压缩得过密。
- 无效房间页提供“输入其他房间号”而非只有返回按钮，恢复路径合理。
- 个人中心错误为整页失败，但恢复后状态不会残留；按钮文字明确。
- 首页公开比赛服务失败时采用局部降级，赛事创建入口和排行榜仍可用，符合大规模活动所需的故障隔离。
- 普通用户访问 Admin 深链会静默回首页。安全上没有泄露，但可以用一次性 toast 提示“需要系统管理员权限”，避免被误解为链接失效。
- 结果页“刷新赛果”对于 paused 状态价值较低，应随状态改成“刷新比赛记录”，或直接实时同步并弱化按钮。
