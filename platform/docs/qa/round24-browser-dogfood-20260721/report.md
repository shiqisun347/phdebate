## 问题

### ISSUE-001：不存在房间的错误反馈过于简短

| 字段 | 内容 |
|---|---|
| 严重度 | Low |
| 分类 | Functional / UX |
| URL | `https://117.50.192.216/competitions/daily-4v4` |
| 复现视频 | [issue-001-repro.webm](videos/issue-001-repro.webm) |

**问题描述**

匿名用户从赛事详情选择“立即参赛 → 搜索房间”，输入格式正确但不存在的六位房间号后，接口返回 404。主线复核原始结果截图时确认弹窗实际上显示了“房间不存在。”，因此最初“完全没有反馈”的判断不准确；真实问题是反馈字号和信息量都较弱，没有复述房间号，也没有告诉学生下一步该核对号码还是联系房主，容易被误判为按钮无响应。

**复现步骤**

1. 匿名打开 4v4 赛事详情页。
   ![赛事详情](screenshots/issue-001-step-1.png)
2. 点击“立即参赛”，再选择“搜索房间”。
   ![参赛弹窗](screenshots/issue-001-step-2.png)
3. 输入六位房间号 `123456`，按钮进入可点击状态。
   ![输入房间号](screenshots/issue-001-step-3.png)
4. 点击“登录或注册后进入”，接口返回 404；弹窗底部只显示简短的“房间不存在。”。
   ![简短错误结果](screenshots/issue-001-result.png)

### ISSUE-002：手机观战页的辩题被截断且没有可发现的展开方式

|---|---|
| 严重度 | Low |
| 分类 | Content / Responsive UX |
| URL | `https://117.50.192.216/rooms/296152/watch` |
| 复现视频 | N/A（静态问题） |

**问题描述**
