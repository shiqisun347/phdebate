# 真人断线安全暂停规则

## 唯一规则

真人席位在比赛开始后始终属于原参赛者，系统、房主、管理员和其他辩手都不能把该席位转换为 AI。

- 断线未满 60 秒：保留真人身份、席位、比赛进度和控制权。
- 断线达到 60 秒：立即中断未完成的发言、冻结计时并暂停整场比赛。
- 真人重新连接：只恢复在线状态，不自动继续比赛。
- 全部真人重新连接后：由房主或系统管理员明确点击“继续比赛”。
- 账号被停用：立即按真人不可用处理并安全暂停，不转移成 AI。

## 暂停时保存的内容

- 当前阶段和剩余时间。
- 自由辩论当前方、轮次和剩余时间。
- 已确认的真人 ASR 文字。
- 房间席位、原用户 ID 和房主身份。
- 断线、暂停、重连和继续操作的只追加事件记录。

暂停后到达的迟到 ASR 结果不会继续修改已中断发言。弱网设备保存的最终文字可通过原发言提交接口完成一次幂等补交，但系统不会生成替代发言。

## 已永久移除

- 真人席位自动转换为 AI。
- 辩手主动放弃席位并让 AI 继续。
- 席位恢复申请、房主审批和管理员直接恢复接口。
- 房间投影中的恢复申请字段和相关页面控件。
- 将历史接管席位作为可执行 AI 辩手的状态机分支。

数据库迁移 `0034_retire_ai_takeover` 会把遗留席位还原为真人（无用户的异常席位改为空席），并使旧的待处理恢复申请失效。历史比赛事件仍保留用于审计，但不会参与当前比赛运行。

## 验收要求

1. 任意真人断线 59 秒时比赛仍保持原阶段，席位类型为 `human`。
2. 任意真人断线达到 60 秒时房间状态变为 `paused`，不得创建 AI 发言。
3. 同一房间多名真人同时断线只暂停一次，每名断线者保留独立超时记录。
4. 其他房间的状态、计时和发言不受影响。
5. 真人重连不会自动恢复计时；仍有真人离线时，继续、重试和跳过均被服务端拒绝。
6. 当前 API 和 Web 运行时代码中不存在旧席位类型或恢复申请路由。
