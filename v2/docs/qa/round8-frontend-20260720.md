# Round 8 前端产品体验、性能与可访问性审计

日期：2026-07-20  
范围：赛事大厅、赛事详情、个人中心、房间大厅、结果页、系统管理导航与全局布局  
保护边界：未修改 `DebateStage`、LiveKit、AudioWorklet、PCM、实时音频 hooks、浏览器播放队列、MOSS 或任何 voice runtime 文件。

## 产品与视觉判断

平台服务于需要快速组织大量真人与 AI 辩论的学生。页面的首要工作不是展示技术架构，而是让用户在几秒内看懂“这是什么赛事、当前是什么状态、下一步能做什么”。本轮沿用现有深蓝、紫色和青色体系，没有进行模板化重做；参照字节系产品常见的清晰层级、克制状态色、紧凑但可扫读的操作密度，集中修复真实操作阻塞和语义不一致。

## 浏览器审计结论

使用 `agent-browser` 在桌面和 390×844 手机视口检查公开大厅、赛事详情和结果页，并核对键盘结构、控制尺寸、页面溢出、控制台与网络状态。

### 已修复问题

1. **高：从大厅进入赛事详情后保留原滚动位置。**
   - 用户点击页面下部的“查看规则”后，赛事详情可能从中部开始显示，错过赛事名称、状态和“立即参赛”。
   - 赛事详情现在在 slug 变化时于绘制前回到页面顶部。
   - 单元测试与生产浏览器用例均增加回归断言。

2. **高：390px 手机端四个赛事栏目逐字换行。**
   - 原四栏平均挤压，出现“赛\n事\n介\n绍”式标签，点击区域和阅读顺序都不自然。
   - 标签改为 44px 高、禁止换行的横向滚动栏，并加入滚动吸附、边缘留白和滚动条隐藏；页面本身不会产生横向溢出。
   - 生产浏览器用例增加每个标签高度与 `white-space: nowrap` 断言。

3. **中：匿名观众在未结束赛果页被突出引导至个人中心。**
   - 匿名观众没有个人比赛档案，原主按钮会把其送入登录流程，偏离“继续观看本场”的意图。
   - 非最终赛果现在优先显示“返回比赛现场”；匿名观众返回 `/watch`，参赛者或管理员返回 `/debate`。
   - “返回个人中心”仅对当前参赛者或有控制权限的用户显示。

4. **中：页面主标题和导航状态缺少一致语义。**
   - 个人中心、排行榜、系统管理和房间大厅原本没有正确的一级标题；房间大厅还先出现 `h2` 再出现 `h1`。
   - 上述页面现在均有唯一、顺序正确的 `h1`。
   - 全局导航为当前页面增加 `aria-current="page"` 和克制的选中态，降低用户在后台和公开页面之间迷失的概率。

5. **中：键盘用户无法快速跳过全局导航。**
   - 根布局增加“跳到主要内容”链接，仅在获得焦点时显示，并将主内容锚点统一为 `#main-content`。

6. **低：复制房间邀请链接只有图标变化，反馈不明显。**
   - 房间大厅增加可见的“已复制”短反馈和 `aria-live` 通知，按钮无障碍名称同步更新。

7. **低：手机端顶部主要操作触摸高度不一致。**
   - 手机导航中的小按钮统一达到 44px 最小触摸高度；面板标题中的图标与文字统一对齐。

## React / Next.js 性能审计

已确认并保留的合理实现：

- 大厅赛事为主请求，公开比赛和排行榜独立并行加载，次要面板失败不会阻塞创建比赛。
- 公开比赛轮询仅在页面可见时执行，并阻止请求重入。
- 排行榜目录使用 `Promise.all` 并行获取，切换筛选时使用请求序列避免旧响应覆盖新状态。
- 结果页长逐字稿和时间线使用 `content-visibility: auto`，录音使用 `preload="none"`，避免长比赛一次性初始化所有媒体。
- 后台重模块已采用动态导入，长列表和筛选器没有在本轮重新合并进首屏包。
- 本轮没有新增第三方依赖或客户端全局状态。

后续可继续做、但不应与当前稳定版本混在一次发布的工作：

- 将公开大厅、赛事详情和排行榜的首屏目录数据迁移到 Server Component / Suspense，减少全屏文字 loading；需要同步设计认证 Cookie、缓存和错误边界，适合独立性能轮次。
- 将赛事详情和个人中心中密集的一行 JSX 拆成纯展示组件，降低维护风险；当前未发现运行性能瓶颈，因此不为“代码看起来更整齐”扩大本轮改动面。
- 后台主页面虽已降至约 1172 行，仍可继续把 tab 数据装载器拆成独立 hooks，但应配合后台操作 E2E 一起进行。

## 发布后验收清单

1. 在手机端从大厅页面下部点击“查看规则”，确认新页面滚动位置为顶部。
2. 在 390×844 查看赛事详情，确认四个栏目单行显示、可横向滑动、页面本身无横向滚动。
3. 匿名打开暂停或进行中的 `/rooms/:code/result`，确认主操作是“返回比赛现场”，且没有“返回个人中心”。
4. 参赛者打开同一结果页，确认可返回比赛现场和个人中心。
5. 房间大厅复制邀请链接，确认出现“已复制”，两秒后自然消失。
6. 用键盘 Tab 聚焦“跳到主要内容”，确认可直接进入主内容；检查大厅、排行榜和后台当前导航状态。
